Что дальше? Скачай Python, открой файл из папки «Загрузки» и заверши установку. IDLE появится вместе с Python.

Установить выбранное

Python и IDLE

Скачайте .exe и запустите его. Проверьте список программ и подтвердите установку. Пока файл не подписан, Windows может предупредить о неизвестном издателе.

Автоматическая установка доступна для Windows. Для выбранной системы откройте ссылки на загрузку выше.

КИТОНИНФОРМАТИКА IDLE входит в установку Python. Можно добавить другие программы.
