# Установка программ для ОГЭ и ЕГЭ по информатике

Статическая адаптивная страница для выбора ОГЭ/ЕГЭ, операционной системы и программ.

## Локальный просмотр

Откройте `site/index.html` в браузере или запустите локальный HTTP-сервер из каталога `site`.

## Состав

- ОГЭ: Python + IDLE, КуМир и LibreOffice.
- ЕГЭ: Python + IDLE, PyCharm и LibreOffice.
- Windows и macOS: ссылки на установщики или страницы скачивания.
- Linux: инструкции по установке Python + IDLE и страницы загрузки для остальных программ.
- Windows x64: восемь отдельных `.exe` собираются под каждый вариант выбора. Python устанавливается вместе с IDLE; Python, PyCharm и LibreOffice устанавливаются из каталога WinGet. КуМир скачивается с сайта НИИСИ, сверяется по SHA-256 и устанавливается в тихом режиме.
- На странице загрузки всегда показано предупреждение, что файлы пока не подписаны КИТОН и могут вызывать SmartScreen.

## Проверки и публикация

`node --test site/setup-core.test.mjs` проверяет все восемь вариантов выбора. Workflow `Windows installers` собирает `.exe` для Windows x64 и на pull request выполняет реальные установки Python/IDLE, PyCharm, LibreOffice и КуМир на одноразовом Windows runner.

После push в `master` GitHub Actions обновляет release с тегом `windows-installer-current`, который использует сайт для загрузки выбранного `.exe`. Отдельный workflow публикует каталог `site/` в GitHub Pages.

Подпись издателя КИТОН не настроена. Чтобы убрать предупреждение неизвестного издателя, потребуется сертификат подписи кода и защищённый секрет для сборки.
